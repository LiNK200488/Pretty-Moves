# Pretty Moves

**Pretty Moves** brings source-faithful Pokémon FireRed battle animations to Pokémon Red, Blue and Yellow in Gen1Recomp.

Instead of inventing new effects, the mod recreates the original FireRed move presentation as closely as possible, including animation timing, sprites, flashes, battler motion and sound effects.

## Features

- FireRed-style move animations for Gen 1 battles
- Source-faithful timing, positioning and effects
- FireRed battle sound effects
- Shared status and stat-change animation replacements
- Transform support
- Substitute, Poké Ball and other special battle sequences
- Compatibility work for **Potato Voxel**
- Compatibility work for **Battle Art Voxel**
- Support for Battle Art's animated Pokémon sprites, including Transform

## Requirements

- Gen1Recomp
- Pokémon Red, Blue or Yellow
- A legally obtained clean **Pokémon FireRed (USA v1.0 / revision 0)** ROM for the FireRed animation and audio resources

## Installation

Download **Pretty_Moves_v1.0.0.zip** from the Releases page and install it through Gen1Recomp's mod system.

The mod keeps the internal ID `firered_battle_anims` for compatibility with existing settings and integrations.
